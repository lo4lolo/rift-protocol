# 짭로란트 · RIFT PROTOCOL

독자 제작한 브라우저 전술 FPS 0.54. 원작의 공개 플레이 규칙을 분석하여 5대5, 라운드당 한 목숨, 구매 경제, 코어 설치·해체를 구현했습니다. 원작 실행 파일을 역공학하거나 비공개 코드·추출 모델을 사용한 결과물은 아닙니다.

## 웹에서 바로 플레이

**[게임 시작](https://lo4lolo.github.io/rift-protocol/)** — PC Chrome/Edge에서 요원을 고르고 **작전실 입장 → 작전 시작 → 클릭하여 전장에 진입**. 9개 봇이 자동으로 채워집니다. Esc로 마우스를 해제합니다.

GitHub Pages 공개판은 브라우저 안에서 실행되는 **혼자 하는 봇 연습**입니다. 친구와 온라인 대전을 제공하는 서버는 아직 공개 배포되지 않았습니다. 아래의 Node 서버를 실행하면 기존 멀티플레이를 사용할 수 있습니다.

## 바로 실행

1. Node.js 22 이상이 설치된 Windows PC에서 **시작하기.cmd**를 실행합니다.
2. 처음에는 필요한 패키지를 설치합니다. 이후 브라우저가 열립니다.
3. 콜사인과 방 코드를 입력하고 **작전실 입장**을 누릅니다.
4. 혼자라면 **훈련봇으로 5대5 채우기 → 작전 시작**을 누릅니다.
5. **클릭하여 전장에 진입**을 눌러 마우스를 잠급니다. 구매 시간에는 B로 상점을 엽니다.

서버 종료는 실행 창에서 Enter. 개발 중에는 `npm start` 후 `http://localhost:4175`로 접속하고 Ctrl+C로 종료합니다. HTML 더블클릭으로는 실행되지 않습니다.

## 친구와 플레이

서버를 실행한 **한 PC의** 시작 창에 표시된 LAN 주소를 친구에게 전달합니다. 같은 Wi-Fi/유선 네트워크에서 그 주소를 열고 같은 방 코드를 입력하면 됩니다. 각자 localhost를 열면 서로 다른 서버입니다. 방장은 최초로 입장한 사람이며 최대 10명입니다. 빈자리는 자동으로 채워지지 않으므로 훈련봇 버튼은 친구가 모두 입장한 뒤 사용하세요.

Windows 방화벽 안내가 표시되면 사용할 사설 네트워크에서 Node.js 접속 허용이 필요할 수 있습니다. 이 작업에서 방화벽이나 공유기 설정은 변경하지 않았습니다. 외부 인터넷 매칭·공개 서버는 아직 배포하지 않았습니다. LAN 실기기 검증도 아직입니다.

## 구현된 경기

- 원본 제작 해안 연구소 맵: A/B 거점, 중앙 및 양측 진입로, 엄폐물.
- 서버 판정: 이동·벽 충돌·발사 속도·탄약·헤드샷·체력·방어력·크레딧·목표 수행.
- 구매 20초, 전투 100초, 설치 후 40초. 12라운드 후 공수 교대, 먼저 13승. 방장이 연장전을 켜면 12:12부터 2점 차 승리가 필요합니다.
- 권총/소총/기관단총/저격총/나이프. 움직이거나 점프하며 쏘면 탄 퍼짐 증가, 조준·앉기로 감소. 소총·기관단총 연사 시 위쪽 반동.
- 독자 요원 3종, 라운드마다 Q 기본 능력 1회 및 구매형 C/궁극기 V. 연막 12초, 정찰 4초, 전방 돌진.
- 10명 방, 방별 격리, 방장 이전, 중도 입장 시 다음 라운드 대기, 팀원 관전, 봇 길찾기·교전·설치·해체.
- 입력 ACK와 미처리 입력 재계산, 100ms 원격 보간, 최대 250ms 서버 사격 지연 보정.
- 무기 드롭/줍기와 탄약 보존, 봇 반응 시간·몸통 조준, 브라우저별 설정 저장.
- 전투 피드백: 탄도, 피격 표시, 킬 피드, 발소리·총성·코어 경고음, 미니맵, 점수판.

## 검증

구매 단계에서 B를 누르면 **팀 구매 지원**을 사용할 수 있습니다. 주무기가 없는 플레이어는 기관단총·소총·저격총 중 하나를 요청하고, 아군은 자신의 크레딧으로 해당 무기를 지급할 수 있습니다. 요청 취소와 구매 단계 종료 시 자동 취소를 지원합니다. 현재 지원 구매의 환불은 없습니다.

`npm run verify`가 규칙/네트워크 테스트, 봇 경기, 10개 소켓 접속, Edge 브라우저 2개 조작을 순서대로 실행하도록 구성돼 있습니다. 현재 기본 실행에서는 브라우저 조작 단계를 건너뛰고 규칙/봇/소켓만 실행합니다. 실행한 단계가 실패하면 실패 코드로 종료합니다. 상세 결과는 `evidence/verification.json`, 화면은 `evidence/*.png`입니다. Edge가 설치되지 않은 컴퓨터는 브라우저 하네스의 channel 설정을 설치된 브라우저에 맞춰야 합니다.

브라우저 차단 이전 버전에서 왕복 200ms 이상을 넣은 실제 브라우저 테스트가 통과했습니다. 이후 변경의 화면 검증 근거로 사용하지 않습니다. 실제 인터넷 지연 환경 전체, 물리 PC 10대, 장시간 서비스 안정성, 마우스 감각의 원작 일치도는 미검증입니다. 현재 결과와 다음 작업은 [인수인계.md](인수인계.md)를 참고하세요.


## 0.3 시각·판정 개선

- 창문·출입구·거점 표시·외곽 스카이라인을 갖춘 독자 해안 연구소 맵.
- 관절이 움직이는 요원 3종과 형태가 다른 무기 5종. 1인칭 무기 전용 렌더링, 저격 스코프, 총구 섬광.
- 머리·몸통·다리 판정을 분리하고 회전·앉기·지연 보정에 반영.
- 시각 하네스가 무기별 화면과 모델 전시 화면을 저장합니다. 2026-10-16 전체 7단계 및 37개 테스트 통과.
- 실제 PC 간 LAN, 외부 배포, 장시간 안정성은 아직 미검증입니다. 외관은 독자 저폴리곤 스타일이며 원작의 모델·애니메이션 품질과 같지는 않습니다.
## 0.4 요원 능력

| 요원 | C 구매형 능력 | V 궁극기 |
|---|---|---|
| 베일 | 섬광 파동: 250 크레딧, 전방 14m 적 시야 2초 방해 | 그림자 이동: 6점, 전방 최대 14m 이동 |
| 펄스 | 충격 파동: 300 크레딧, 전방 16m 적에게 피해 45 | 전장 스캔: 7점, 모든 적 위치 8초 공개 |
| 제트스트림 | 상승 기류: 200 크레딧, 위로 도약 | 폭풍 집중: 7점, 12초 이동/공중 탄퍼짐 억제 및 돌진 2회 |

C는 B 상점에서 최대 2회분을 구매합니다. 남은 구매 충전은 다음 라운드에 보존됩니다. 섬광·충격파는 벽에 차단되고 아군에게 적용되지 않습니다. 순간이동도 벽을 관통하지 않습니다.

궁극기 점수는 처치·사망·설치·해체마다 1점씩 얻습니다. 공수 교대와 새 경기에서는 구매 충전과 궁극기 점수를 초기화합니다. V 키는 기존 X 무기 내려놓기와 E 줍기를 유지하기 위한 현재 배치입니다.

이 능력들은 원작 요원의 능력을 그대로 복제한 것이 아닌 독자 규칙입니다. 투사체 비행·회피 방향별 섬광 강도·능력 장착 애니메이션은 아직 없습니다. 0.6부터 봇도 거리·체력·가시성에 따라 추가 능력과 궁극기를 사용합니다.
## 0.5 팀·경기 진행

작전실에서 자신의 시작 팀을 선택할 수 있습니다. 팀당 최대 5명이며 경기 중에는 변경되지 않습니다. 방장은 훈련봇을 비우거나 다시 채울 수 있습니다.

연장전은 작전실에서 방장이 선택합니다. 기본은 꺼짐(먼저 13승)입니다. 켜면 12:12 이후 2점 차 승리가 필요하며, 각 연장 라운드마다 공수를 바꾸고 5,000 크레딧·기본 장비로 초기화합니다. 별도 무승부 투표나 라운드 상한은 아직 없습니다.

경기 종료 화면에서 방장이 같은 구성으로 재시작하거나 작전실로 돌아가 팀·설정을 바꿀 수 있습니다. 참가자는 같은 연결을 유지합니다.
## 0.6 훈련봇 전술

운반자는 라운드마다 A/B를 번갈아 공략하고 동료는 호위와 우회로 나뉩니다. 설치 후 공격팀은 주변을 지키고 수비팀은 한 명이 해체하며 나머지가 엄호합니다. 사람이 해체 중이면 봇은 엄호합니다.

봇은 방어구와 능력을 구매하고 거리·체력·반응 시간에 따라 사용합니다. 연막이 시선 구간 어느 곳에 있어도 적을 직접 볼 수 없으며, 등 뒤 먼 적을 즉시 알아채지 않습니다. 아직 고정 거점 중심의 단순 전술이며 사람 수준의 판단·학습 기능은 아닙니다.
## 0.7 준비 이동·관전

구매 단계에는 출발 구역 안에서 이동·점프할 수 있습니다. 청록색 시작 장벽은 전투 시작 시 사라집니다. 구매 중 발사/능력 사용은 여전히 막습니다.

사망 후 살아 있는 팀원을 [ / ] 키나 화면 버튼으로 골라 관전할 수 있습니다. 대상이 사망하면 다른 생존 팀원으로 전환하며, 다음 라운드에는 본인 시점으로 돌아옵니다.

### 자동 검증과 마우스

사용자가 다른 작업 중 마우스를 빼앗기는 문제가 있어 브라우저 조작 검증은 기본 차단했습니다. npm run verify는 규칙/봇/소켓/지연 소켓 6단계만 실행하고 브라우저 7단계를 skipped로 기록합니다. 최신 테스트 수는 인수인계와 evidence 기록을 확인하세요. 개별 브라우저 하네스도 차단됩니다. 사용자 명시 허락 없이 RUN_BROWSER_TESTS=1을 설정하지 마세요.

구매/관전 동작은 차단 이전의 실제 지연 브라우저에서 확인했습니다. 이후 수정한 장벽 무늬·안내 문구와 사망 시 진입 버튼 숨김은 문법 검사만 수행했고 새 화면 확인은 미실시입니다.
## 0.8 탄도·피해

권총은 30m 이후, 기관단총은 20m/35m 이후 피해가 줄어듭니다. 다리 피해는 일반 총기의 몸통 대비 85%, 저격총은 80%입니다. 소총과 저격총은 현재 거리 감쇠가 없습니다.

높이 3m 이하의 낮은 엄폐물은 복합 소재로 취급하고 탄환이 실제로 통과하는 길이에 따라 관통력과 피해를 소모합니다. 높은 건물 벽은 관통 불가입니다. 나이프는 관통하지 않습니다. 무기별 관통력과 감쇠값은 독자 조정값이며 원작 수치의 정확한 복제가 아닙니다.

서버 명중 결과에 머리/몸통/다리와 관통 여부가 포함됩니다. 명중 안내 문구를 추가했지만 브라우저 차단 상태이므로 화면 배치는 아직 재확인하지 않았습니다.
## 0.9 일시적 연결 끊김 복구

연결이 끊기면 30초 동안 기존 자리를 보관합니다. 같은 브라우저 탭은 2초 간격으로 복귀를 시도하며 같은 ID·팀·장비·점수·입력 순번을 이어갑니다. 복귀 정보는 탭의 sessionStorage에만 저장됩니다.

끊긴 동안 경기는 계속되고 캐릭터는 피해를 받을 수 있습니다. 입력은 멈추며 코어는 떨어집니다. 방장은 접속 중인 참가자에게 이전됩니다. 30초가 지나면 자리를 정리하고, 참가자가 전부 사라진 방도 삭제합니다.

서버 종료·다른 PC·새 브라우저 탭으로 경기 상태를 옮기는 기능은 아닙니다. 복귀 서버 로직은 10개 실제 소켓 × 8회로 확인했으며, 브라우저 자동 재시도 화면은 아직 미검증입니다.

### 0.22 전투 보고서

사망하거나 라운드가 끝나면 오른쪽에 이번 라운드의 준/받은 피해가 표시됩니다. 상대·무기·부위별 명중 횟수와 실제 체력/방어 감소량을 보여줍니다. 다음 라운드에는 초기화됩니다. 화면 검증은 사용자 요청에 따라 보류 중입니다.

### 0.23 처치 도움

같은 라운드에서 적의 체력과 방어력을 합쳐 50 이상 감소시킨 뒤 팀원이 처치하면 도움(A)이 기록됩니다. 점수판은 K/D/A를 표시합니다. 도움은 추가 구매 자금이나 궁극기 포인트를 주지 않습니다. 비피해 능력 도움은 아직 포함하지 않습니다.

### 0.24 섬광·정찰 도움

섬광이나 정찰이 적에게 적용된 동안 팀원이 그 적을 처치해도 도움(A)이 올라갑니다. 피해 도움과 동시에 충족해도 한 번만 기록합니다. 효과 종료 뒤 유예 시간은 없으며 연막/이동/자기 강화는 포함하지 않습니다. 앞선 0.23의 비피해 능력 미포함 설명은 이 버전에서 섬광·정찰에 한해 변경되었습니다.

### 0.25 도움 알림

처치 도움을 얻으면 본인 화면 하단에 피해/능력 기여 알림이 3초 표시됩니다. 재접속으로 지난 알림을 다시 재생하지 않으며, 도움 누계는 점수판에서 확인합니다. 배너의 실제 화면 배치는 아직 검증하지 않았습니다.

### 0.26 주무기 구매 취소

구매 단계에 직접 산 주무기는 상점의 구매 취소 버튼으로 환불할 수 있습니다. 여러 번 구매했다면 마지막 구매부터 되돌리며 이전 무기와 탄약을 복원합니다. 이전 라운드 무기나 팀 지원 무기 자체는 환불되지 않습니다. 방어구·능력 환불은 아직 없습니다.

### 0.27 보호막·보조 능력 구매 취소

이번 구매 단계에 산 보호막과 C 능력도 상점에서 취소할 수 있습니다. 보호막은 구매 전 방어력으로, 능력은 구매 전 수량으로 돌아갑니다. 이전 라운드에서 가져온 물품 자체는 환불되지 않습니다. 0.26의 미지원 안내는 이 버전에서 변경되었습니다.

### 0.28 무기에 따른 이동

나이프를 들면 가장 빠르게 이동하고, 저격총을 들거나 조준하면 느려집니다. 걷기·앉기·피격 감속도 함께 적용됩니다. 돌진과 순간 이동의 거리는 무기에 영향을 받지 않습니다. 현재 이동 수치는 프로젝트 자체 조정값입니다.

### 0.29 지연 검증 확장

기본 비브라우저 검증에 지연 중 나이프·조준 저격총·권총 이동과 연속 무기 전환을 포함했습니다. 브라우저를 열지 않고 실제 소켓과 공유 예측 코드로 검사합니다. 실제 화면의 부드러움은 별도 확인이 필요합니다.

### 0.30 라운드 기록

Tab 점수판 아래에서 최근 12라운드의 우리 팀 승패와 종료 이유를 확인할 수 있습니다. 공수 교대 후에도 승패 기준은 유지됩니다. 기록은 현재 서버의 경기 동안만 남으며 새 경기나 서버 종료 시 보존되지 않습니다.

### 0.31 나이프 오른쪽 클릭

나이프를 들고 오른쪽 클릭하면 더 짧은 거리에서 강하게 공격합니다. 기본 공격보다 다음 공격까지 오래 기다려야 하며 한 번 누를 때 한 번 공격합니다. 수치는 자체 조정값이며 등 뒤 추가 피해는 아직 없습니다.

### 0.32 뒤쪽 나이프 공격

상대의 뒤쪽에서 나이프로 명중하면 추가 피해를 줍니다. 총기에는 적용되지 않으며, 서버가 지연 보정된 상대 방향으로 판정합니다. 0.31의 뒤쪽 피해 미지원 안내는 이 버전에서 변경되었습니다. 실제 타격감은 아직 화면에서 검증하지 않았습니다.

### 0.33 이동 동작

다른 플레이어의 옆걸음·앉기·공중 자세·착지 동작을 구분했습니다. 화면 없이 관절 계산과 프레임 속도별 보행 주기를 검사했으며, 실제 화면에서의 자연스러움은 아직 확인하지 않았습니다.

### 0.34 재장전 표시

재장전 진행에 맞춰 무기를 내리고 탄창을 움직인 뒤 조준 위치로 복귀합니다. 재장전 또는 무기 꺼내기 중에는 저격 조준경을 내립니다. 동작 계산과 취소 시 복원은 검사했으나 실제 화면 품질은 아직 확인하지 않았습니다.

### 0.35 궁극기 충전 구체

동쪽·서쪽 통로의 밝은 결정 가까이에서 F를 3초간 누르면 궁극기 포인트 1점을 얻습니다. 움직이거나 공격·피격되면 처음부터 다시 수집해야 합니다. 라운드마다 재생성되며 코어 설치 후에는 수집할 수 없습니다. 이미 궁극기가 가득 차 있으면 구체가 소모되지 않습니다.

### 0.36 봇의 구체 수집

봇도 근처의 충전 구체를 수집합니다. 가장 가까운 담당 한 명이 접근하고, 사람이 수집 중이면 양보합니다. 코어 운반·회수·설치 후 대응과 적 교전을 우선합니다.

### 0.37 코어 폭발

설치된 코어가 시간 만료로 폭발하면 양 팀 모두 거리별 피해를 받습니다. 16m 밖은 안전하며 벽으로 막을 수 없습니다. 사망하면 주 무기를 떨어뜨리고, 다른 플레이어에게 처치 보상은 지급하지 않습니다. 폭발 범위·피해는 이 게임의 자체 설정입니다. 화면 효과와 소리는 구현했지만 실제 재생 검증은 하지 않았습니다.

### 0.38 봇의 폭발 대피

공격 봇은 폭발 8초 전부터 안전 지대로 대피합니다. 수비 봇은 남은 시간이 짧을 때 이동 거리와 해체 진행도를 계산하여 성공이 불가능하면 후퇴합니다. 해체 절반 저장과 진행 중인 해체를 고려하며, 탈출 중에는 교전보다 이동을 우선합니다.

### 0.39 다른 플레이어의 재장전 동작

다른 플레이어가 재장전하면 팔과 무기가 내려가고 탄창이 움직입니다. 취소·완료 시 조준 자세로 돌아옵니다. 보이는 적의 재장전 동작은 표시하지만 탄약 수는 공개하지 않습니다. 실제 화면에서의 자연스러움과 손·탄창 접촉은 아직 검증하지 않았습니다.

### 0.40 산탄총 브리처

1100 크레딧의 근거리 산탄총입니다. 6발 탄창, 한 발당 산탄 10개, 클릭마다 한 번 발사하며 거리에 따라 피해가 감소합니다. 벽을 관통하지 않습니다. 구매 취소와 동료 구매 지원이 가능합니다. 수치와 외형은 자체 설계이며 원작 무기를 그대로 재현한 것은 아닙니다.

### 0.41 승리 후 코어 대피

수비팀 전멸로 승리해도 설치된 코어는 남아 있습니다. 기존 폭발 시간이 더 이르지 않다면 4초 뒤 폭발합니다. 생존자는 움직여 대피할 수 있으며, 폭발로 사망하면 장비를 잃습니다. 승패·점수·라운드 보상은 다시 지급되지 않습니다. 종료 대기 중 사격과 능력은 사용할 수 없습니다. 시간은 자체 설정입니다.

### 0.42 경형 보호막

400 크레딧으로 방어력 25를 구매할 수 있습니다. 중형은 기존처럼 1000 크레딧에 방어력 50입니다. 남은 방어력보다 높은 방어력을 주는 상품만 구매할 수 있으며, 교체는 정가입니다. 이번 구매 단계에서 산 보호막은 취소해 이전 방어력과 비용을 복원할 수 있습니다. 경형을 산 직후 중형으로 바꾸려면 먼저 구매 취소하면 중복 지출을 피할 수 있습니다.

### 0.43 지원 요원 헤이븐

밝은 회녹색 복장의 지원가입니다. Q는 15m 안의 조준 방향 아군 체력을 60 회복하고, 적절한 아군이 없으면 자신을 회복합니다. C는 자신의 방어력 25를 보충합니다(최대 50). V는 7포인트로 20m 안의 벽·연막에 가리지 않은 아군 체력을 100까지 회복합니다. 사망자는 되살리지 않으며, 회복할 대상이 없으면 횟수나 포인트를 소비하지 않습니다. 고유하게 설계한 능력 구성입니다.

### 0.44 회복 조준 개선

Q는 화면 중앙의 3차원 조준선으로 가장 앞에 있는 플레이어를 판정합니다. 높이 차이와 앉은 자세를 반영하며, 앞의 다른 플레이어나 벽을 통과해 뒤쪽 아군을 회복하지 않습니다. 유효한 아군이 없으면 기존처럼 부상한 자신을 회복합니다.

### 0.45 팀 채팅

입장 후 T로 팀 채팅을 열고 Enter로 전송합니다. Esc로 닫을 수 있습니다. 최대 200자, 초당 1회이며 전송 당시 같은 팀에게만 전달합니다. 채팅 중에는 이동·사격이 멈추고, 전송 후 화면의 게임 복귀 버튼으로 돌아갑니다. 메시지는 서버 메모리의 제한된 이벤트와 화면 최근 8개에만 남으며 영구 저장하지 않습니다. 음성 채팅과 전체 채팅은 없습니다.

### 0.46 채팅 전송 확인

서버의 전송 확인 후에만 작성 내용을 지웁니다. 전송 제한·연결 문제에서는 내용을 남기고 안내합니다. 확인 중에는 중복 전송하지 않으며, 한글 조합 중 Enter로 잘못 전송되는 것을 막도록 입력 상태를 처리합니다. 실제 한글 키보드 동작은 아직 검증하지 않았습니다.

### 0.47 지원 봇의 아군 회복

헤이븐 봇은 교전 중이 아닐 때 15m 안의 체력 60 이하 아군을 우선 회복합니다. 여러 아군의 잃은 체력 합이 100 이상이면 준비된 범위 회복을 사용합니다. 벽·연막·앞의 플레이어 차단을 따르고 코어 해체와 대피를 우선합니다. 먼 아군을 찾아 이동하는 전략은 아직 없습니다.

### 0.48 중간 입장

진행 중인 경기에 새로 들어오면 다음 라운드까지 관전합니다. 대기자는 전멸 판정과 해당 라운드 보상에서 제외되며 사망 기록도 늘지 않습니다. 다음 라운드에 정상 참가합니다. 잠시 끊겼다가 복귀하는 기존 플레이어는 새 입장으로 처리하지 않고 원래 상태를 유지합니다.

### 0.49 친구에게 봇 자리 양보

시작 전 로비가 10명으로 가득 찼더라도 훈련봇이 있으면 친구 입장 시 봇 한 명이 자리를 양보합니다. 실제 플레이어는 제거하지 않습니다. 경기 시작 후에는 자동 교체하지 않으므로, 가득 찬 경기에는 로비로 돌아온 뒤 친구를 받으세요.

### 0.50 착지 후 정확도 회복

점프나 상승 기류에서 착지하면 탄퍼짐이 잠시 커지고 0.18초 동안 정상으로 돌아옵니다. 사격 자체는 가능하지만 정확한 첫 발을 원하면 잠깐 기다려야 합니다. 봇도 같은 규칙을 사용합니다. 시간과 배율은 자체 설정입니다.

### 0.51 점사 소총 트라이어드

2050 크레딧, 24발 탄창의 3점사 소총입니다. 한 번 클릭하면 0.08초 간격으로 최대 세 발을 발사하고 실제 발사한 탄만 소비합니다. 버튼을 계속 눌러도 새 점사를 반복하지 않습니다. 재장전·무기 교체·사망·연결 단절·라운드 종료 시 남은 점사는 취소됩니다. 상점 구매와 동료 구매 지원이 가능하며 원작 특정 무기를 그대로 복제한 수치는 아닙니다.

### 0.52 전투 중 봇 이동

봇은 적을 보고 있을 때도 재장전하거나 사격을 쉬는 동안 옆으로 이동합니다. 벽에 막히면 반대 방향을 확인하고, 사격하거나 예약된 점사가 남아 있으면 이동을 멈춥니다. 엄폐물을 찾아 숨거나 다른 플레이어를 피해 가는 전략은 아직 없습니다.

### 0.53 동시 사격 통신 검사

기본 검증에 10개 로컬 연결의 동시 산탄·점사 검사를 추가했습니다. 산탄 100개와 점사 30발의 자기 발사 결과 전달, 중복 이벤트, 탄약 상태를 확인합니다. 실제 여러 PC나 화면 성능 검증과는 별개입니다.
