# 성공 조건과 하네스

## 성공 조건

| 범위 | 통과 조건 | 하네스 |
|---|---|---|
| 경기 규칙 | 구매/탄약/승패/설치/해체/교대가 서버 상태와 일치 | Node 내장 test + assert |
| 입력 경계 | NaN, 오래된 seq, 변조된 구매값·체력·좌표를 신뢰하지 않음 | 규칙 및 실제 WebSocket 테스트 |
| 충돌 | 대각선 이동 속도 동일, 벽 관통 차단, 벽 뒤 피해 차단 | 규칙/길찾기 테스트 |
| 멀티플레이 | 같은 방 공유, 다른 방 격리, 방장 권한, 마지막 사람 종료 시 정리 | 임시 서버 + 실제 ws 클라이언트 |
| 목표 수행 | 봇이 출발점에서 거점까지 이동하여 설치 | 길찾기 테스트 |
| 전체 경기 | 10봇 경기가 13승에 도달하고 상태값이 유효 | 고속 시뮬레이션 soak |
| 연결 부하 | 10개 실소켓이 30Hz 입력을 보내며 모두 상태 수신 | network-load |
| 사용자 경로 | 두 독립 브라우저 입장, 시작, 구매창, 실제 키 이동·발사·재장전·능력 | Playwright + Edge |
| 화면 | 로비/작전실/구매/전장/두 번째 클라이언트/점수판 캡처 확인 | PNG 수동 시각 점검 |

## 실행과 산출물

`npm run verify` → `scripts/verify.mjs`가 하위 검증을 순차 실행합니다. 실패 시 즉시 실패 상태를 저장하고 종료합니다. 테스트용 임시 서버는 종료하고, 공개 디버그 엔드포인트는 만들지 않습니다.

- `npm test`: 규칙·길찾기·실소켓 테스트.
- `npm run test:browser`: Edge 자동화. 두 개의 독립 브라우저 저장소를 사용.
- `npm run test:load`: 10개 실제 WebSocket 연결, 5초 부하.
- `node scripts/soak.mjs`: 가속된 봇 경기. 실제 18분을 기다린 부하 시험과 구분.
- `evidence/verification.json`: 단계별 통과 상태.
- `evidence/browser-results.json`, `network-load.json`, `soak-results.json`: 개별 결과.
- `evidence/*.log`: 하네스 표준 출력, `evidence/*.png`: 화면 증거.

## 확인하지 못한 범위

실제 PC 간 LAN, 외부 인터넷과 높은 ping, 브라우저별 감도 차이, 현실의 10명 사용자, GPU별 성능, 장시간 누수, 장애 복구, 공개 서비스 보안. 계정 인증·매칭·랭킹·음성채팅도 구현 범위에 포함되지 않았습니다. 입력 재실행·보간·250ms 제한 rewind와 왕복 200ms 브라우저 검증은 구현됐습니다. 이것이 모든 인터넷 환경이나 경쟁 게임 수준의 치트 방어를 검증한 것은 아닙니다.

## 발견하여 수정한 문제

- 브라우저 시점의 상하 방향이 서버 조준과 반대였음 → 동일한 pitch 방향 적용.
- 브라우저 부하에서 서버 시간 진행이 느려짐 → 실제 경과 시간을 누적하는 60Hz 고정 시뮬레이션.
- 벽에 막히는 봇 경로 → 공유 충돌체 기반 그리드 길찾기와 거점 도달 테스트.
- 무기 전환 시 탄약 복원 및 재장전 취소 → 무기별 탄약 보존과 회귀 테스트.
- 잘못된 구매 객체가 문자열 변환을 유발할 수 있음 → 허용 문자열 목록 검증.
- 이벤트 목록을 계속 재전송함 → 연결별 마지막 전달 이벤트 이후만 전송.
- 스냅샷 주기를 콜백 횟수로 세어 실제 주기가 낮아짐 → 실제 경과 시간으로 20Hz 조절.

## 0.2 추가 하네스

- `scripts/latency-proxy.mjs`: 실제 상·하행 메시지 각각 100ms + 0~20ms 지터. 운영 서버와 분리.
- `scripts/combat-check.mjs`: 두 브라우저에서 구매/무기 교환/조준 피해/킬/승패 동기화.
- `tests/netcode.test.mjs`: ACK 재실행, 입력 폭주, 과거 판정 제한, 회전 경계, 입력 중단 시 중력.
- `tests/loot.test.mjs`: 탄약 보존, 중복 줍기 방지, 사망 드롭, 주무기 교환.
- 지연 검증 결과: `evidence/delayed/browser-results.json`, `evidence/combat/results.json`.

## 0.3 추가 하네스와 검증 범위

- tests/art.test.mjs: 머리/몸통/다리/팔 판정, 회전 및 앉기, 모델 유효성/크기/관절, 무기 길이와 내부 깊이. 기존 넓은 박스의 가장자리가 머리로 맞던 문제를 방지.
- scripts/visual-check.mjs: 게임 서버와 실제 Edge 1440×900에서 총기 5종·스코프를 확인하고, 동일 모델 함수로 3요원/5무기 전시 화면을 촬영. 테스트 전시용 상태는 브라우저 하네스 내부에서만 생성.
- evidence/visual: 스크린샷과 결과 JSON. 이미지의 미적 적합성은 자동 수치 검사와 별도로 직접 열어 점검.
- 전체 진입점에 visual 단계 추가: 총 7단계 / 37개 테스트. 2026-10-16 통과.
- 이 PC의 10명 화면 FPS 샘플 57/61/61. 하네스 통과 하한은 25 FPS이며, 해당 환경 외의 성능 보장이나 10명 실사용자 검증은 아님.
- 단순 신체 판정 영역은 시각 관절을 완전히 따라가지 않음. 머리카락·총기 부속은 피격 대상이 아님. 렌더링 성공이 원작 시각 품질과의 일치를 뜻하지 않음.
- 총기가 다른 부품을 투과해 보이던 문제는 별도 무기 장면을 렌더링하되 내부 깊이 검사를 유지하여 수정.
- 인수인계의 버전과 별개로 각 검증 파일의 날짜는 report-time.mjs가 실행 당시 한국 시간으로 생성.

## 0.4 능력 하네스

tests/abilities.test.mjs는 구매 비용과 최대 충전, 라운드/교대 초기화, 전방 각도·벽·팀 차단, 방어력·사망·드롭, 궁극기 포인트 및 입력 중단 시 상승/착지를 확인합니다.

scripts/abilities-check.mjs는 실제 두 브라우저에서 세 요원을 각각 선택하고 구매 버튼·C/V 키를 사용합니다. 지연 중계 뒤 서버 소비 상태와 상대 섬광/체력 및 HUD를 확인합니다. 궁극기 획득을 기다리는 대신 테스트 소유 Game에 점수를 준비하므로 획득 규칙은 단위 테스트 증거로 구분합니다. 공개 디버그 엔드포인트는 없습니다.

전체 검증에 abilities-delayed를 포함하여 8단계입니다. 장시간 실사용 밸런스와 봇의 추가 능력 전술은 이 검사에 포함되지 않습니다.

## 0.5 경기 진행 하네스

tests/match-flow.test.mjs는 팀 정원·방장 권한·단계 제한, 연장전 점수/교대/경제, 로비 복귀 상태를 검증합니다. scripts/match-flow-check.mjs는 두 실제 Edge 컨텍스트에서 버튼 동작과 양쪽 화면 전환을 확인합니다. 후반 경기 상태는 하네스 내부에서 준비합니다. 전체 진입점에 match-flow가 추가되어 9단계/47개 테스트입니다.

## 0.6 전술 봇 하네스

tests/tactics.test.mjs는 연막 구간 차단·전방 시야·역할 분담·해체 담당·능력 반응을 검증합니다. scripts/tactics-soak.mjs는 고정 난수 시드 3개로 10봇 경기를 가속하여 끝까지 실행하고 양쪽 거점 설치/능력/역할 발생 및 상태 범위를 확인합니다. 전체 10단계/51개 테스트이며 실제 사용자 난이도·장시간 네트워크 검증과 구별합니다.

## 0.7 준비·관전 및 검증 운영 변경

구매 장벽은 tests/preparation.test.mjs 3개로 양팀 이동·점프·예측·입력 중단을 검사합니다. preparation-check는 차단 이전에 실제 지연 브라우저로 동작을 확인했습니다.

2026-10-16 사용자가 다른 작업 중 마우스가 빼앗긴다고 알렸습니다. 이후 기본 verify는 비브라우저 4단계만 실행하고 브라우저 7단계를 생략합니다. 개별 하네스도 browser-consent.mjs가 차단합니다. 환경변수 RUN_BROWSER_TESTS는 사용자 명시 허락 없이 활성화하지 않습니다. 생략 결과는 passed:null/skipped:true이며 통과로 합산하지 않습니다.

장벽 줄무늬와 사망 시 진입 버튼 숨김의 후속 화면 확인은 미실시입니다. 새 결과 JSON과 차단 이전 결과를 구별합니다.

## 0.8 탄도 하네스
