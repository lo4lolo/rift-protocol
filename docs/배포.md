## 다른 PC에서 수정하고 갱신하기

Node.js 22 이상에서 저장소를 clone하고 `npm ci --ignore-scripts`로 설치합니다. `npm test`, `npm run build:pages`, `node scripts/pages-check.mjs`로 확인한 후 main에 push하면 GitHub Actions가 자동으로 Pages를 갱신합니다.

`dist`는 자동 생성물입니다. 직접 수정하지 마세요. `public`과 게임 규칙을 수정합니다. Pages 빌드에서는 루트 경로를 상대 경로로 바꾸고 WebSocket 연결을 전용 Worker의 PracticeSession으로 교체합니다. 원래 Node 서버 모드는 그대로 유지합니다.

## 검증 범위

2026-10-16: 180개 Node 테스트 및 7개 비브라우저 하네스 통과. 배포용 모듈 16개의 경로를 확인하고 생성된 Worker를 Node의 worker_threads 브리지에서 실행해 입장/9봇/구매/상태 수신을 확인했습니다.

사용자 요청으로 브라우저 실행, 마우스/키보드 조작, 화면·음향 검증은 수행하지 않았습니다. WebGL 성능과 실제 브라우저 조작은 별도 확인이 필요합니다. 탭을 닫거나 새로고침하면 연습 경기가 초기화됩니다.

GitHub Pages 설정은 GitHub Actions 배포 방식입니다. 인증 정보는 저장소에 포함하지 않습니다. 연구용 외부 원문, 기존 릴리스 ZIP, PC별 로그와 실행 증거는 Google Drive 원본 폴더에 보존합니다.
